# Simple CRM

A small workspace for customer relationships: contacts, opportunities and the next action, kept as plain files an agent can read and write.

1. Add contacts to **contacts.csv**.
2. Track opportunities in **deals.csv**.
3. Record the next action in **Follow-ups.md**.

Open the CSV files as tables and make this project your own. No setup or scripts are required. All people and companies in the examples are fictional.
